# TooltipFix 1.2.0

本轮只做两件事：把 **toast 九宫格的固定边框画对**，以及把 **Jade 信息框的透明留白真正贴到屏幕边**。全部改动都在本模组内，不改上游 mod、不改原版 jar、不要求材质包作者改包。

## 修复

### 1. 系统提示框（toast）裁掉一格像素，感叹号变形

**现象**：装 CozyUI 类材质包后，短提示框里的「!」图标末端缺一层，看起来像被压扁；左右边框也一起变窄。

**原因**：CozyUI+ 的 `toast/system.png` 是 640×256 的 4 倍图，mcmeta 声明 `width 160 height 64`、`border 16/26/12/8`。旧实现按「整体等比缩放」处理：用 `k = min(w/基准宽, h/基准高)` 统一缩，通知高 32 时 `k = 24/34`，把顶部 26 压成 24 —— 而感叹号正好画到顶部第 100/104 像素，最后一层就被切掉。

**做法**：横、纵两个方向分别计算。固定边框能按 1:1 画就 1:1 画；空间不够时**保留较大的装饰区，只从对侧内侧裁掉一点内部留白**，绝不缩放固定边框本身。短通知（32 高）现在保持顶部 26 完整，只从底部 8 里收 2 像素。

- 影响变体：1.20.1、1.21.1 Fabric / NeoForge、26.1.2 Fabric / NeoForge
- 未装材质包时完全不介入，原版画法逐字节一致

### 2. Jade 信息框的透明区域被算进尺寸，框贴不到屏幕边

**现象**：把 Jade 覆盖层固定到屏幕左上角时，框和屏幕之间留一条缝，贴不到边；挖方块时的进度条也跟着错位。

**原因**：材质包的 `jade:tooltip/<theme>_background.png` 是 400×400 的画布，mcmeta 声明九宫格基准 100×100、border 24，但画布里真正有像素的部分只有中间一部分，四周是透明边。旧实现直接把整张 400×400 当 100×100 铺，于是透明边也被算进「框的大小」，看起来就是框缩水、贴不到边。

**做法**：按 PNG 的实际不透明像素边界量出透明留白，再按 mcmeta 的基准尺寸换算成 GUI 单位。留白只加在**绘制**上，不改 Jade 的布局和命中区域，所以进度条位置和原来一致。Jade 圆角色框自带的那 1 单位外边框也一并保留，避免贴边出现细缝。

- 影响变体：1.20.1、1.21.1 Fabric / NeoForge（26.1.2 原生支持，不需要）

### 3. 挖矿进度条不再被「框尺寸替换」牵连

1.21.1 之前的做法是整体替换 `BoxStyle`，而 Jade 的 `BoxStyle.getSprite()` 对进度偏移返回空、对进度配色回落到默认值，于是进度条会失去原本的偏移和颜色。现在改成**只重定向根框**的绘制，子框、进度条仍走 Jade 自己的代码，进度几何与配色保持原样。

### 4. 材质包卸载后不再残留旧贴图

资源重载时清空本模组的 sprite 缓存（`[tooltipfix] GUI sprite caches cleared after resource reload`），卸包后立即回到原版外观，不需要重启游戏。
